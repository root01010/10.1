# AutosalonLab10 - Лабораторна робота №10

Тема: **Класи та об'єкти**.

Проект реалізований на C# Windows Forms. Програма динамічно створює об'єкти керування на формі:

- лівий клік по формі створює новий елемент;
- парний елемент - `Button`, непарний - `Label`;
- правий клік видаляє всі динамічно створені кнопки;
- кнопка "Очистити всі елементи" видаляє всі створені елементи;
- у файл `generated_controls_log.txt` записуються дії користувача.

## Використані теми C#

- класи та об'єкти;
- оператор `new`;
- динамічне створення `Button` і `Label`;
- властивості `Parent`, `Location`, `Size`, `Text`, `BackColor`;
- події `MouseClick`, `Click`, `DoubleClick`, `Resize`;
- область видимості змінних;
- оператори `is` та `as`;
- робота з колекцією `List<Control>`;
- запис у файл через `File.AppendAllText`.

## Запуск

1. Відкрити папку `src` у Visual Studio.
2. Відкрити `AutosalonLab10.csproj`.
3. Запустити проект кнопкою **Start** або клавішею **F5**.
